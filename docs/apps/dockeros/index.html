DockerOS

Boot into a focused Docker workstation. DockerOS packages a minimal Debian base with a guided installer and a web-first operating model for a dedicated x86-64 Docker host.

Designed around the job

What DockerOS does

01

Purpose-built host

Start with a minimal Linux environment designed around Docker Engine and Compose.

02

Web-managed operations

Use a browser-accessible container manager while retaining normal command-line access.

03

Repeatable installation

Build a bootable image and install to a selected disk with explicit destructive-action warnings.

Connections and boundaries

It works with what you choose.

Container registries, package mirrors, local network services, and any third-party containers the operator chooses to install.

Nothing essential is bundled

The installer can erase a selected disk. Back up data, verify the target drive, and test on non-production hardware before relying on a development image.
