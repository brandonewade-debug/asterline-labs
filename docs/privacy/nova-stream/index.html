Nova Stream Privacy Policy

How Nova Stream handles Invidious connections, local profiles, account tokens, history, and media requests.

Effective September 21, 2026

Scope and developer role

This policy applies to Nova Stream for iPhone and Apple TV. Nova Stream connects to an Invidious server chosen by the user and does not operate an Asterline account, video catalog, advertising system, analytics backend, or media relay.

The app processes information needed for features, but Asterline Labs generally does not receive that information because requests are made from the device to the configured server or media host.

Data Nova Stream handles

  • The HTTPS address of the Invidious server you select.
  • An optional scoped Invidious API token, normalized server identity, and local profile association. Password entry remains with the selected Invidious server.
  • Local profiles, subscriptions or imported channel lists, favorites, hidden channels, watch later or saved items, searches, playback preferences, watch history, and cached feed or artwork data.
  • Saved or locally downloaded media files created when the user invokes an available feature.
  • Video identifiers and playback metadata needed to request formats, thumbnails, captions, regular video, or live playback.

How the data is used

The data is used to authenticate to your chosen Invidious server, load feeds and search results, subscribe or unsubscribe when authorized, record history when the user granted that scope, resolve playback, and retain your on-device library. Nova Stream does not use it for Asterline advertising, cross-app tracking, data brokerage, or sale.

Where data goes

  • Your Invidious server: Search, feed, account, subscription, history, metadata, and format requests go to the server you configure.
  • Media hosts: Playback and images may be requested from hosts returned by Invidious. Live playback can contact YouTube or Google video-delivery endpoints directly without signing into a Google account.
  • Optional self-hosted components: A compatible relay path, when configured by the server owner, is controlled by that operator rather than Asterline Labs.
  • Apple: TestFlight and App Store distribution are handled by Apple.

Server operators and media hosts may see ordinary request information such as IP address, user agent, requested video, and account activity. Choose an operator you trust and review its privacy practices.

Retention and deletion

Account tokens are intended for Keychain or protected app storage; library state and caches remain on the device. Use Nova Stream’s disconnect, profile, history, saved-item, import, or download controls where available, or delete the app to remove its local container. Device backups can retain data according to Apple settings.

Nova Stream does not create an Asterline account, so there is no Asterline account to delete. Delete an Invidious account with its server operator. Disconnecting Nova Stream removes the local token but does not by itself delete the remote account or all server logs.

Tracking, advertising, and analytics

Nova Stream is not designed to include Asterline advertising, behavioral analytics, or cross-app tracking. Invidious operators, media hosts, Apple, and other external services apply their own logging and privacy practices.

Content and authorization

Users are responsible for using servers, downloads, streams, and content only when authorized. Nova Stream does not grant rights to third-party media, bypass provider permissions, or include a video catalog.

Security

Nova Stream requires a normalized HTTPS server URL for current setup paths and rejects credential-bearing server URLs. No software can guarantee security. Keep the operating system current, use a trusted server, and never send account tokens or private URLs to support.

Children

Nova Stream is not directed to children under 13, and Asterline Labs does not knowingly operate a service that collects children’s personal information. Parents and guardians control the server, media, and account access configured on a device.

Questions and changes

Material changes will be posted here with a new effective date. For a privacy request, use the support page and include “Nova Stream privacy” without including credentials.
